# 🚀 CapabilityGap AI  
### Adaptive Skill Assessment & Capability Gap Analysis Platform

> An AI-powered platform that identifies skill gaps and generates personalized learning roadmaps based on career goals.

---

## 📌 Overview

CapabilityGap AI is an intelligent system designed to help students understand **what they lack**, not just what they score.

The platform uses **AI-generated assessments, resume analysis, and performance analytics** to identify capability gaps across knowledge, speed, and confidence, and provides a **personalized roadmap**.

---

## 🎯 Problem Statement

Students often prepare without understanding their real skill gaps. Existing platforms:
- Provide scores but no insights  
- Lack personalized guidance  
- Do not align skills with job roles  

---

## 💡 Solution

CapabilityGap AI:
- Generates **role-based AI assessments**  
- Evaluates performance (accuracy, speed, confidence)  
- Detects **capability gaps**  
- Analyzes **resume skills**  
- Provides **AI-powered learning roadmap**  

---

## ✨ Features

- 🤖 AI-generated questions (Gemini API)  
- 📊 Capability scoring system  
- ⚠️ Skill gap detection  
- 📄 Resume analysis  
- 🧠 Adaptive assessment  
- 📈 Dashboard analytics  
- 🗺️ Personalized roadmap  

---

## 🧠 Workflow

```
User → Select Role → AI Assessment → Attempts Stored → Capability Score → Gap Analysis → AI Roadmap → Dashboard
```

---

## 🏗️ Tech Stack

- Frontend: React.js, Tailwind CSS  
- Backend: Supabase  
- Database: PostgreSQL  
- AI: Google Gemini API  
- Charts: Chart.js  
- Deployment: Vercel  

---

## 🚀 Setup

```bash
git clone https://github.com/shanus0007/CapabilityGap.git
cd capabilitygap
npm install

```
